# MLOps Lesson 4 - Experiment Tracking (Base)

Базовая версия проекта для урока по трекингу экспериментов машинного обучения.

## Описание

Проект содержит реализацию двух моделей машинного обучения:
1. **Логистическая регрессия** (`model1.py`)
2. **Решающее дерево** (`model2.py`)

Обе модели обучаются на датасете рукописных цифр (sklearn.datasets.load_digits).

## Структура проекта

- `config.py` - конфигурационные параметры моделей
- `data.py` - загрузка и подготовка данных
- `model1.py` - логистическая регрессия (базовая версия)
- `model2.py` - решающее дерево (базовая версия)
- `requirements.txt` - зависимости проекта

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите модели:
```bash
python3 model1.py
python3 model2.py
```

## Задания

На основе этой базовой версии создайте ветки для различных систем трекинга:

1. **ClearML** - ветка `clearml`
2. **Weights & Biases** - ветка `wandb`
3. **MLFlow** - ветка `mlflow`

Каждая ветка должна содержать интеграцию с соответствующей системой трекинга экспериментов.
